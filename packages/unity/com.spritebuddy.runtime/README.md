# SpriteBuddy for Unity

Plays animations exported from [SpriteBuddy](https://github.com/Patrick-Hammond/spritebuddy):
add a **SpriteBuddy Sprite** component, drag in the exported `.anims.json`, and pick an
animation. Per-frame timing, loop, ping-pong and play-once modes, frame offsets, live layers,
frame events, and normal maps for URP's 2D lights.

Full instructions and examples:
<https://github.com/Patrick-Hammond/spritebuddy-runtimes/tree/main/packages/unity>
